# 🛒 FreshCart Enquire App

FreshCart Enquire is a simple and user-friendly web application designed to help customers explore grocery and daily-use products and make enquiries about product availability, price, and other details.

## 📌 About the Project

The **FreshCart Enquire App** provides a digital platform where users can browse products and send enquiries to a store.

Instead of directly visiting the shop to check product availability or details, customers can use the application to view products and submit their enquiries conveniently.

## 🎯 Objectives

- Provide an easy way to explore grocery products
- Allow customers to enquire about products
- Display product information clearly
- Improve communication between customers and local stores
- Provide a simple and responsive user experience

## ✨ Features

- 🛍️ Product listing
- 🔍 Product search
- 📂 Product categories
- 💰 Product price display
- 📦 Product availability information
- 📝 Product enquiry form
- 📞 Contact information
- 📱 Responsive design
- ⚡ Simple and interactive interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and functionality
